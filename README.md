# StudentSync

StudentSync is a Flask-based student productivity and authentication web application.

## Features
- User Registration & Login
- Flask-Login Authentication
- Login Success Email Notifications
- Profile Picture Upload
- Secure Environment Variables with .env
- SQLite Database
- Deployment Ready with Gunicorn + Procfile

## Tech Stack
- Python
- Flask
- Flask-Login
- Flask-Mail
- SQLite
- HTML/CSS
